\# IT Labs Portfolio



A practical portfolio documenting hands-on work in networking, Windows administration, system diagnostics, and cybersecurity fundamentals.



The purpose of this repository is to turn theoretical knowledge into repeatable laboratory exercises supported by technical documentation, command outputs, packet captures, and conclusions.



\## Current Modules



\### Networking



1\. \[IP, TCP, and UDP Analysis](networking/01-ip-tcp-udp-analysis/)

2\. \[Common Ports and Services](networking/02-common-ports-and-services/)



More modules will be added as the portfolio develops.



\## Repository Structure



Each numbered directory represents a separate technical topic. Practical exercises related to that topic are stored directly inside its module directory.



Individual labs may include:



\* lab objectives,

\* tools and commands used,

\* step-by-step procedures,

\* observations and technical findings,

\* screenshots or packet-capture evidence,

\* conclusions and troubleshooting notes.



\## Tools Used



\* Windows 11

\* Windows PowerShell

\* Wireshark

\* Git and GitHub

\* Built-in Windows networking utilities



\## Skills Demonstrated



\* TCP/IP and UDP traffic analysis

\* DNS query and response analysis

\* TCP connection establishment

\* Network flow identification using the five-tuple

\* Windows TCP and UDP endpoint inventory

\* Port-to-process mapping

\* Network connectivity diagnostics

\* Technical documentation in English



\## Privacy and Security



Screenshots and command outputs are reviewed before publication. Sensitive information such as public IP addresses, usernames, hostnames, organizational domains, and unnecessary system details is removed or masked.

This repository is continuously expanded with new practical exercises as part of my ongoing IT and cybersecurity development.
