# IT Labs Portfolio

A practical portfolio documenting hands-on work in networking, Windows administration, system diagnostics, and cybersecurity fundamentals.

The purpose of this repository is to turn theoretical knowledge into repeatable laboratory exercises supported by technical documentation, command outputs, packet captures, and evidence-based conclusions.

## Current Modules

### Networking

1. [IP, TCP, and UDP Analysis](networking/01-ip-tcp-udp-analysis/)
2. [Common Ports and Services](networking/02-common-ports-and-services/)
3. [Wireless Network Technologies](networking/03-wireless-network-technologies/)
4. [Server Services and Infrastructure Validation](networking/04-server-services-and-infrastructure/)

More modules will be added as the portfolio develops.

## Repository Structure

Each numbered directory represents a separate technical topic. Practical exercises and supporting evidence are stored inside the related module directory.

Individual modules may include:

- lab objectives and environment descriptions;
- tools and commands used;
- step-by-step validation procedures;
- observations and technical findings;
- screenshots, packet captures, or structured datasets;
- conclusions and troubleshooting notes.

## Lab Environment

- Proxmox VE
- OPNsense
- Windows Server 2025 with Active Directory Domain Services, DNS, and DHCP
- Windows 11 domain client
- Windows PowerShell
- Wireshark
- Git and GitHub

## Skills Demonstrated

- TCP/IP and UDP traffic analysis
- DNS query, response, and service-discovery validation
- DHCP scope, lease, and client troubleshooting
- TCP connection establishment and five-tuple analysis
- Windows TCP and UDP endpoint inventory
- Port-to-process and service mapping
- Active Directory, Kerberos, LDAP, SMB, and Windows Time validation
- Wireless network and interference analysis
- Evidence-based diagnostic reasoning
- Technical documentation in English

## Privacy and Security

Screenshots and command outputs are reviewed before publication. Sensitive information such as credentials, public IP addresses, personal usernames, hardware identifiers, organizational domains, and unnecessary system details is removed or masked. Purpose-built lab names and private addresses may remain when they are necessary to explain the exercise.
