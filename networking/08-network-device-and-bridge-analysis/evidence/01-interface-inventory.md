### Link state

Command:

~~~bash
ethtool nic0 | grep -E 'Speed|Duplex|Auto-negotiation|Link detected'
~~~

Result:

~~~text
Speed: 100Mb/s
Duplex: Full
Auto-negotiation: on
Link detected: yes
~~~

Finding: the adapter supports Gigabit Ethernet, but the current path negotiated at 100 Mb/s. The old 100 Mb/s switch is the limiting physical component.
