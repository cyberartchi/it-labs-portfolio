# Wireless Network Technologies

This module documents practical Windows-based analysis of wireless networking technologies. The exercises cover Wi-Fi connection parameters, adapter capabilities, latency and DNS testing, nearby channel usage, and Bluetooth/NFC hardware inventory.

## Labs

| Lab | Description |
|---|---|
| [Wireless Environment Analysis](01-wireless-environment-analysis/) | Inspect the active Wi-Fi connection, adapter capabilities, gateway and Internet latency, and DNS resolution. |
| [Channel and Interference Analysis](02-channel-and-interference-analysis/) | Survey nearby wireless networks and evaluate channel separation, signal levels, and possible interference. |
| [Bluetooth and NFC Inventory](03-bluetooth-and-nfc-inventory/) | Identify the Bluetooth adapter and check whether Windows detects an NFC or proximity device. |

## Tools

- Windows 11
- Windows PowerShell
- Command Prompt
- `netsh`
- `ping`
- `nslookup`

## Skills Demonstrated

- Reading Wi-Fi interface and driver information
- Comparing 2.4 GHz and 5 GHz channel usage
- Interpreting signal strength and latency
- Verifying DNS name resolution
- Identifying Bluetooth and NFC-related hardware
- Documenting results while protecting private network information

## Privacy

SSIDs, BSSIDs, MAC addresses, interface identifiers, and unrelated environment details were masked or omitted before publication.
